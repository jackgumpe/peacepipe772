# PeacePipe 772

Static catalog site for PeacePipe Smoke Shop in Fort Pierce, Florida.

## Stack

- Astro static output
- No cart, checkout, authentication, or client-side app runtime
- Cloudflare Pages target

## Commands

```sh
npm install
npm run build
npm run preview
```

Cloudflare Pages:

- Build command: `npm run build`
- Output directory: `dist`
